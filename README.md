# 3DCheck

Анализатор дефектов и оптимизированности 3D-моделей.

Программа загружает модель, проверяет её геометрию по набору фильтров и выдаёт список проблем
с итоговой оценкой качества от 0 до 100.

## Установка

```powershell
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```powershell
python src/main.py                          # спросит путь к файлу
python src/main.py samples/broken_sphere.obj # путь аргументом
```

Тестовые модели (чистая, переуплотнённая, дефектная) генерируются командой:

```powershell
python tools/make_samples.py
```

## Поддерживаемые форматы

`.obj`, `.stl`, `.ply`, `.glb`, `.gltf`, `.off`, `.3mf`, `.dae` — всё, что экспортируется из Blender.

## Что проверяется

| Фильтр | Что ищет |
| --- | --- |
| Лишние полигоны | избыточную триангуляцию плоских участков, вырожденные полигоны нулевой площади, превышение полигонального бюджета |
| Неправильные нормали | вывернутые полигоны, несогласованный обход вершин, незамкнутый меш, инвертированный объём |
| Дубли и скопления вершин | совпадающие вершины, скопления вершин в микрообъёме, вершины вне полигонов |

Каждый фильтр даёт штраф, итоговая оценка — `100 − сумма штрафов`.

## Структура

```
src/analyzer.py       ядро анализа, класс MeshAnalyzer
src/main.py           консольный интерфейс
tools/make_samples.py генератор тестовых моделей
samples/              готовые модели для проверки
```

## Планы

- GUI на customtkinter с 3D-вьювером и вращением модели
- подсветка проблемных зон прямо на модели
- экспорт отчёта в файл
