# 3DCheck

Анализатор дефектов и оптимизированности 3D-моделей.

Программа загружает модель, проверяет её геометрию по набору фильтров и выдаёт список проблем
с итоговой оценкой качества от 0 до 100.

## Установка

```powershell
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Графический режим с 3D-вьювером — двойной клик по `run.bat` или командой:

```powershell
python src/app.py
python src/app.py samples/model.obj
```

Консольный режим:

```powershell
python src/main.py
python src/main.py samples/model.obj
```

Свои модели для проверки складывайте в папку `samples/`. Прогнать по ним интерфейс
и получить скриншоты в `build/smoke` можно так:

```powershell
python tools/smoke_test.py
```

## Сборка exe

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name 3DCheck --icon assets\logo.ico --add-data "assets;assets" --collect-all OpenGL --collect-data customtkinter --collect-data trimesh --collect-all rtree --paths src src\app.py
```

Готовое приложение — `dist\3DCheck\3DCheck.exe`. Переносить нужно всю папку `dist\3DCheck`
целиком, exe без соседних файлов не запустится.

| --- | --- |
| Вращение | ЛКМ + движение |
| Сдвиг | ПКМ или Shift+ЛКМ |

Кнопка «Скриншот» сохраняет вьюпорт в PNG — удобно для пояснительной записки.

## Поддерживаемые форматы

`.obj`, `.stl`, `.ply`, `.glb`, `.gltf`, `.off`, `.3mf`, `.dae` — всё, что экспортируется из Blender.

Полигоны и нормали проверяются одинаково точно в любом формате. А вот дубли вершин
достоверно видны только в `.obj`, `.ply` и `.off`: остальные контейнеры (`.glb`, `.stl`, `.fbx`,
`.dae`) физически разрезают вершины по нормалям и UV, поэтому там совпадения показываются
справочно и не влияют на оценку.

## Что проверяется

| Фильтр | Что ищет |
| --- | --- |
| Лишние полигоны | избыточную триангуляцию плоских участков, вырожденные полигоны нулевой площади, превышение полигонального бюджета |
| Неправильные нормали | вывернутые полигоны, несогласованный обход вершин, инвертированный объём |
| Дубли и скопления вершин | совпадающие вершины, скопления вершин в микрообъёме, вершины вне полигонов |
| Нехватка полигонов на изгибах | плавные поверхности, собранные из слишком крупных плоских кусков |

Плоский участок должен состоять ровно из `количество углов − 2` треугольников: для
прямоугольника это два. Всё сверх того считается лишним, даже если превышение всего
на один треугольник.

Изгиб считается угловатым, если соседние полигоны расходятся на 18°–65° и таких
полигонов в одной зоне набирается хотя бы 4. Углы круче 65° считаются задуманным
острым ребром, поэтому куб проверку проходит, а восьмигранный цилиндр — нет.
Пороги задаются константами `FACET_ANGLE_MIN`, `FACET_ANGLE_MAX` и `FACET_REGION_MIN`
в `src/analyzer.py`.

Каждый фильтр даёт штраф, итоговая оценка — `100 − сумма штрафов`.

## Подсветка дефектов

Найденные проблемы рисуются прямо на модели, слои включаются галочками в панели отчёта.

| Цвет | Что означает |
| --- | --- |
| жёлтый | избыточные полигоны на плоских участках |
| синий | нехватка полигонов на изгибах |
| оранжевый | вырожденные полигоны |
| красный | вывернутые нормали |
| малиновый | дублирующиеся вершины |
| бирюзовый | скопления вершин |
| белый | вершины вне полигонов |

