# 3DCheck

Анализатор дефектов и оптимизированности 3D-моделей.

Программа загружает модель, проверяет её геометрию по набору фильтров и выдаёт список проблем
с итоговой оценкой качества от 0 до 100.

## Установка

```powershell
py -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Графический режим с 3D-вьювером:

```powershell
python src/app.py
python src/app.py samples/broken_sphere.obj
```

Консольный режим:

```powershell
python src/main.py
python src/main.py samples/broken_sphere.obj
```

Тестовые модели (чистая, переуплотнённая, дефектная) генерируются командой:

```powershell
python tools/make_samples.py
```

## Управление вьювером

| Действие | Мышь |
| --- | --- |
| Вращение | ЛКМ + движение |
| Сдвиг | ПКМ или Shift+ЛКМ |
| Зум | колесо |
| Сброс вида | двойной клик |

Кнопка «Скриншот» сохраняет вьюпорт в PNG — удобно для пояснительной записки.

## Поддерживаемые форматы

`.obj`, `.stl`, `.ply`, `.glb`, `.gltf`, `.off`, `.3mf`, `.dae` — всё, что экспортируется из Blender.

## Что проверяется

| Фильтр | Что ищет |
| --- | --- |
| Лишние полигоны | избыточную триангуляцию плоских участков, вырожденные полигоны нулевой площади, превышение полигонального бюджета |
| Неправильные нормали | вывернутые полигоны, несогласованный обход вершин, незамкнутый меш, инвертированный объём |
| Дубли и скопления вершин | совпадающие вершины, скопления вершин в микрообъёме, вершины вне полигонов |

Каждый фильтр даёт штраф, итоговая оценка — `100 − сумма штрафов`.

## Подсветка дефектов

Найденные проблемы рисуются прямо на модели, слои включаются галочками в панели отчёта.

| Цвет | Что означает |
| --- | --- |
| жёлтый | избыточные полигоны на плоских участках |
| оранжевый | вырожденные полигоны |
| красный | вывернутые нормали |
| синий | открытые края (дыры) |
| малиновый | дублирующиеся вершины |
| бирюзовый | скопления вершин |
| белый | вершины вне полигонов |

